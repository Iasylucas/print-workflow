# EWA Print Frontend

## Technologies utilisées

- React 19
- TypeScript
- Vite (build tool)
- Tailwind CSS
- TanStack Query (gestion des données)
- TanStack Router
- React Hook Form + Zod (formulaires)
- Zustand (état global)
- Shadcn UI (composants)
- Lucide React (icônes)
- @react-pdf/renderer (génération PDF)

---

## Installation

### Prérequis

- Node.js 18+
- pnpm (ou npm)

### Étapes

1. **Installer les dépendances**

```bash
cd frontend
pnpm install
```
